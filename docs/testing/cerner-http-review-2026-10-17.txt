Client choices for review
- HTTPS required except explicit loopback HTTP. Redirects disabled to prevent token forwarding.
- One request; no automatic retry or refresh. 429/5xx/network/timeout are marked retryable.
- Connect and read inactivity timeouts are configurable, 1–30000 ms each. This is not a total
  request deadline: a slow streaming response can exceed one timeout interval.
- Body capped at 1 MiB. Rejects invalid JSON and incomplete paginated results.
- Generic exceptions omit upstream body, URLs, token, patient values, and root cause.
- Existing mapper policy still skips some malformed individual entries. Partial-result and
  warning behavior needs team approval; it is not established by these tests.
- Caller must authorize the local patient, resolve a trusted vendor-ID link, and get a server-held
  token before calling. A name/DOB match must not supply that trust.
